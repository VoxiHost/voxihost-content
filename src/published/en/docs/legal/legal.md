## Which documents apply

Using VoxiHost means accepting four documents:

| Document | Covers |
|---|---|
| Terms of Service | The contract for the service |
| Privacy Policy | What personal data we process and why |
| Service Level Agreement | Availability commitments and compensation |
| Fair Usage Policy | What a shared host may and may not be used for |

A business workspace accepts the Data Processing Agreement (DPA) as well, because
processing company data as a processor needs its own terms. The DPA is prompted for
the workspace owner, once per workspace.

Each document carries a version number in the form `YYYY.MM`, the month its
published text changed. The published documents are linked in the footer of every
page on the website.

## Accepting a new version

When a version of an applicable document is published with an effective date, the
panel asks you to accept it before you use the dashboard again:

1. Sign in as usual.
2. If a version is waiting for acceptance, you land on the confirmation page
   instead of the dashboard. The page names the document that changed and asks for
   your confirmation.
3. Select **I accept**.
4. The dashboard opens and the panel works as usual.

A pending acceptance does not suspend a service and does not stop a renewal; it
holds the panel, nothing else. Until you accept, the panel stays closed, including
for tools connected to it.

## What your acceptance records

For each acceptance the panel stores:

- the document and its version,
- the date and time,
- the workspace, when the document is the DPA,
- your IP address and browser user agent.

The IP address and the browser user agent are stored encrypted. They exist so a dispute
can be answered with the same evidence for both sides: which text, which version,
when.

Accepting a later version never overwrites the record of an earlier one. Each
version is recorded separately, so the history can be read in order.

## How a new version reaches you

We announce a change at least 30 days before it takes effect, so there is time to
read it. Affected customers receive an in-app notification and an e-mail naming the
document and the date it becomes binding.

The version you accept is the version recorded.

## Checking what you accepted

The exact set, with versions and dates, is part of the data export described in
[Profile & preferences](/docs/account/settings/).

## Business documents

An invoice request copies the workspace details stored at that moment, so correct
the legal identity and invoicing address before requesting a document. An invoice
that was already issued is not rewritten: a correction is issued as a separate
document.

## If a document is not readable

The published documents are linked in the site footer. If a link returns a missing
page, tell support which document and version the confirmation page names, instead
of accepting blind, because the version you accept is the version recorded.
